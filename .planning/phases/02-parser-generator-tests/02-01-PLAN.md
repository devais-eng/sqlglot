    - `FUNCTIONS`: spread PostgresParser.FUNCTIONS, then add:
      - `"MATCH": lambda args: exp.Anonymous(this="PARLANTE_MATCH", expressions=args)`
      - `"PHRASE_MATCH": lambda args: exp.Anonymous(this="PARLANTE_PHRASE_MATCH", expressions=args)`
    - `RANGE_PARSERS`: spread PostgresParser.RANGE_PARSERS, then override `TokenType.OPERATOR` with:
      `lambda self, this: self.expression(exp.Operator(this=this, operator=self._prev.text, expression=self._parse_bitwise()))`
      At the point this lambda is called, `self._prev` holds the consumed OPERATOR token (e.g. "@@@") and `self._curr` is the RHS start. Use `self._parse_bitwise()` for the RHS (correct precedence for comparison-level operators). Use `self.expression(...)` to preserve comment tracking (matches `_parse_operator` pattern at parser.py line 9849).

Must use TRANSFORMS override — auto-discovered `operator_sql` is silently ignored because exp.Operator is already registered in the base TRANSFORMS dict (generator.py line 225). The f-string is acceptable here as no public generator API exists for emitting the operator field literally without the OPERATOR(...) wrapper that binary() adds.

Use `normalize=False` to preserve exact case without depending on normalization settings.

    ```python
    def test_operator_roundtrip(self):
        self.validate_identity("col @@@ 'query'")
        self.validate_identity("col ||| 'query'")
        self.validate_identity("col ### 'query'")
        self.validate_identity("col === 'query'")
        self.validate_identity("col <=> '[0.1,0.2]'")

    def test_match_roundtrip(self):
        self.validate_identity("MATCH(col, 'query')")
        self.validate_identity("PHRASE_MATCH(col, 'query')")

    def test_no_regression_tsvector(self):
        self.validate_identity("x @@ y")

    def test_no_regression_l2_distance(self):
        self.validate_identity("embedding <-> '[0.1,0.2]'")

    def test_operator_ast_type(self):
        result = self.parse_one("col @@@ 'query'")
        self.assertIsInstance(result, exp.Operator)
        self.assertEqual(result.args["operator"], "@@@")

    def test_match_ast_type(self):
        result = self.parse_one("MATCH(col, 'query')")
        self.assertIsInstance(result, exp.Anonymous)
        self.assertEqual(result.name, "PARLANTE_MATCH")
    ```
